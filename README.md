# Vision-Bridge – Universal Accessibility Assistant

An AI-powered accessibility assistant designed to help people with different disabilities through vision, hearing, motor, cognitive, and speech assistance.

## 🛠️ Tech Stack

- **Frontend:** Next.js 14+, TypeScript, Tailwind CSS
- **UI:** shadcn/ui
- **State:** Zustand, React Query
- **AI:** Google Gemini API
- **PWA:** Service Worker & Offline Support
- **Desktop:** Electron
